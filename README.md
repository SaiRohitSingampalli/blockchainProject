# blockchainProject

Instructions:
1. Navigate to "\blockchainProject\blockchainProject-main\warehousereceipt-DAPP\warehousereceipt-contract" folder on terminal.
2. Run "truffle compile" 
3. Run "truffle migrate --reset"
4. Navigate to "\blockchainProject\blockchainProject-main\warehousereceipt-DAPP\warehousereceipt-app" folder on terminal.
5. Make sure receipts.json file is empty or otherwise replace the data with [].
6. Run "npm install"
7. Run "npm start"
8. open "http://localhost:3000/" on the browser
9. All set to explore the DAPP application.
